# showreel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A public Claude Code plugin whose `/showreel` skill turns a subject and a one-line concept into an approved beat-by-beat brief and then a checked, looping 1920 x 1080 MP4.

**Architecture:** The engine is a set of plain ES modules. Each frame is a pure function of `t`, drawn on Canvas 2D inside headless Chromium (Playwright) and encoded with `ffmpeg-static`. Inks (paper, blueprint, hologram) share one pen interface, so a film draws its geometry once and the active ink decides how it looks. The skill's markdown teaches Claude to write the brief, stop for approval, write the film modules against the engine API, inspect stills, run the rule checks and export.

**Tech Stack:** Node 22, ES modules, Canvas 2D, opentype.js 1.3.4, Playwright (Chromium), ffmpeg-static, `node:test`.

**Spec:** `docs/specs/2026-10-14-showreel-design.md`

## Global Constraints

- Frame 1920 x 1080, 60 fps. Default 120 BPM, 4 beats per bar, 15 bars, 60 beats, 1800 frames.
- Moves start 0.05 s before their beat.
- Easing: critically damped spring `1 - (1 + w t) e^(-w t)` with w in [12, 40], plus exponential in/out. Nothing overshoots.
- Empty border: nothing at rest within 150 px of the sides or 90 px of top and bottom.
- Corner labels: top left `FIG. NN — NAME`, bottom right `BEAT n / total`. Geist 800, 26 px, tracking 0.2 em.
- Geist only: 900 big words, 600 to 800 labels (24 to 28 px, tracked 0.14 to 0.3 em).
- Palette for the three-ink preset: `#EDE6D5` paper, `#1B3ED2` blueprint, `#45F0DD` cyan, `#07080A` black, `#16161A` graphite, `#FFFFFF` white.
- No `Math.random` anywhere in the engine or films. All noise comes from `rng.js`.
- The last frame equals the first.
- Banned in films: particle bursts, glows, lens flares, camera shake, RGB split, crossfades, generic gradients, bouncy easing, holds > 0.5 s.
- Engine path below is written `E/` = `plugins/showreel/skills/showreel/engine/`. Skill root `S/` = `plugins/showreel/skills/showreel/`.
- All engine dependencies live in `E/package.json`. Engine tests live in `E/test/` and run with `npm --prefix E test`.
- Run the `no-slop` skill before every commit: imperative subjects, no AI attribution, comments only for non-obvious invariants.

## Review Focus

1. **Font or film fails to load in the page.** Expect `openRenderer` to reject with the underlying message (HTTP status, stack), never to return blank frames. Pinned in Task 6.
2. **Film directory with spaces or outside the repo.** Expect it to render exactly like any other path. Pinned in Task 6.
3. **`t` equal to the duration.** The loop check renders it; labels must read `BEAT 1 / n`, and no bar index may go out of range. Pinned in Tasks 2 and 6.
4. **Re-export after a crashed run.** Stale PNGs from the earlier run must not end up in the new MP4. Pinned in Task 9.
5. **Pencil wobble updating every frame instead of 8 times a second.** This happens if stroke ids depend on moving geometry. Two frames inside the same 1/8 s tick with static geometry must be pixel-identical. Pinned in Task 7.

```js
export function hash(...parts) {
  let h = 2166136261;
  for (const p of parts) {
    const s = String(p);
    for (let i = 0; i < s.length; i++) { h ^= s.charCodeAt(i); h = Math.imul(h, 16777619); }
    h ^= 0xff; h = Math.imul(h, 16777619);
  }
  return h >>> 0;
}

export function mulberry32(seed) {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

export const rand = (...parts) => mulberry32(hash(...parts));
```

```js
export function makeClock({ bpm = 120, bars = 15, beatsPerBar = 4, fps = 60, lead = 0.05 } = {}) {
  const spb = 60 / bpm;
  const barDur = spb * beatsPerBar;
  const duration = barDur * bars;
  const wrap = t => ((t % duration) + duration) % duration;
  // The epsilon keeps t = k * spb on beat k despite float error in k * spb.
  return {
    bpm, bars, beatsPerBar, spb, barDur, duration, fps, lead,
    totalBeats: beatsPerBar * bars,
    frames: Math.round(duration * fps),
    wrap,
    beatAt: t => Math.floor(wrap(t) / spb + 1e-9),
    barAt: t => Math.floor(wrap(t) / barDur + 1e-9),
    cue: beat => Math.round((beat * spb - lead) * 1e6) / 1e6,
    local: (t, start, dur) => Math.min(1, Math.max(0, (t - start) / dur)),
  };
}

export function labelText(clock, t, barNames) {
  const bar = clock.barAt(t);
  return {
    fig: `FIG. ${String(bar + 1).padStart(2, '0')} — ${barNames[bar]}`,
    beat: `BEAT ${clock.beatAt(t) + 1} / ${clock.totalBeats}`,
  };
}
```

```js
// Normalised so the spring lands exactly on 1 at s = 10 / w and holds there;
// the raw curve only approaches 1, which would break the first == last frame rule.
export function spring(s, w = 20) {
  if (s <= 0) return 0;
  const end = 10 / w;
  if (s >= end) return 1;
  const f = x => 1 - (1 + w * x) * Math.exp(-w * x);
  return f(s) / f(end);
}

export const expoIn = u => (u <= 0 ? 0 : u >= 1 ? 1 : (Math.pow(2, 10 * u) - 1) / 1023);
export const expoOut = u => 1 - expoIn(1 - u);
export const expoInOut = u => (u < 0.5 ? expoIn(u * 2) / 2 : 0.5 + expoOut(u * 2 - 1) / 2);
export const lerp = (a, b, u) => a + (b - a) * u;

// Each key springs from the previous key's target, so a value can be keyed
// beat by beat without tracking where the last move left it.
export function seq(t, from, keys) {
  let v = from, prev = from;
  for (const { at, to, w = 20 } of keys) {
    v += (to - prev) * spring(t - at, w);
    prev = to;
  }
  return v;
}
```

```js
export const dist = (a, b) => Math.hypot(b[0] - a[0], b[1] - a[1]);

export function length(pts, closed = false) {
  let L = 0;
  for (let i = 1; i < pts.length; i++) L += dist(pts[i - 1], pts[i]);
  if (closed && pts.length > 1) L += dist(pts[pts.length - 1], pts[0]);
  return L;
}

export function resample(pts, n, closed = false) {
  const src = closed ? [...pts, pts[0]] : pts;
  const cum = [0];
  for (let i = 1; i < src.length; i++) cum.push(cum[i - 1] + dist(src[i - 1], src[i]));
  const total = cum[cum.length - 1];
  const steps = closed ? n : n - 1;
  const out = [];
  let j = 0;
  for (let i = 0; i < n; i++) {
    const s = (total * i) / steps;
    while (j < cum.length - 2 && cum[j + 1] < s) j++;
    const seg = cum[j + 1] - cum[j] || 1;
    const u = Math.min(1, Math.max(0, (s - cum[j]) / seg));
    out.push([src[j][0] + (src[j + 1][0] - src[j][0]) * u, src[j][1] + (src[j + 1][1] - src[j][1]) * u]);
  }
  return out;
}

// Closed shapes are aligned by the rotation (and direction) of b that is
// nearest to a, so a circle turns into a hexagon without twisting through itself.
export function morph(a, b, u, { closed = false, n = 256 } = {}) {
  const A = resample(a, n, closed);
  let B = resample(b, n, closed);
  if (closed) {
    let best = Infinity, bestB = B;
    for (const cand of [B, [...B].reverse()]) {
      for (let k = 0; k < n; k += 2) {
        let d = 0;
        for (let i = 0; i < n; i += 4) {
          const p = cand[(i + k) % n];
          d += (p[0] - A[i][0]) ** 2 + (p[1] - A[i][1]) ** 2;
        }
        if (d < best) { best = d; bestB = cand.map((_, i) => cand[(i + k) % n]); }
      }
    }
    B = bestB;
  }
  return A.map((p, i) => [p[0] + (B[i][0] - p[0]) * u, p[1] + (B[i][1] - p[1]) * u]);
}

// A curve of fixed length L and constant curvature k, midpoint at (cx, cy)
// with a horizontal tangent, bending upward. k = 0 is a straight line;
// k = 2π / L closes it into a circle centred at (cx, cy - 1 / k).
export function curl(cx, cy, L, k, n = 256) {
  const out = [];
  for (let i = 0; i < n; i++) {
    const s = (i / (n - 1) - 0.5) * L;
    if (Math.abs(k) < 1e-9) out.push([cx + s, cy]);
    else out.push([cx + Math.sin(s * k) / k, cy - (1 - Math.cos(s * k)) / k]);
  }
  return out;
}

export function line(x0, y0, x1, y1, n = 2) {
  return Array.from({ length: n }, (_, i) => [x0 + ((x1 - x0) * i) / (n - 1), y0 + ((y1 - y0) * i) / (n - 1)]);
}

export function cubic(p0, p1, p2, p3, n = 64) {
  return Array.from({ length: n }, (_, i) => {
    const t = i / (n - 1), m = 1 - t;
    const a = m * m * m, b = 3 * m * m * t, c = 3 * m * t * t, d = t * t * t;
    return [a * p0[0] + b * p1[0] + c * p2[0] + d * p3[0], a * p0[1] + b * p1[1] + c * p2[1] + d * p3[1]];
  });
}

export function circle(cx, cy, r, n = 256) {
  return Array.from({ length: n }, (_, i) => {
    const a = (i / n) * Math.PI * 2 - Math.PI / 2;
    return [cx + r * Math.cos(a), cy + r * Math.sin(a)];
  });
}

export function polygon(cx, cy, r, sides, rot = -Math.PI / 2) {
  return Array.from({ length: sides }, (_, i) => {
    const a = rot + (i / sides) * Math.PI * 2;
    return [cx + r * Math.cos(a), cy + r * Math.sin(a)];
  });
}

export function roundRect(x, y, w, h, r, segs = 4) {
  const out = [];
  const corners = [[x + w - r, y + r, -Math.PI / 2], [x + w - r, y + h - r, 0], [x + r, y + h - r, Math.PI / 2], [x + r, y + r, Math.PI]];
  for (const [cx, cy, a0] of corners)
    for (let i = 0; i <= segs; i++) {
      const a = a0 + (i / segs) * (Math.PI / 2);
      out.push([cx + r * Math.cos(a), cy + r * Math.sin(a)]);
    }
  return out;
}

export function gear(cx, cy, teeth, pitchR, rot = 0) {
  const m = (2 * pitchR) / teeth;
  const outer = pitchR + m, root = pitchR - 1.25 * m;
  const profile = [[0, root], [0.2, root], [0.35, outer], [0.65, outer], [0.8, root]];
  const out = [];
  for (let k = 0; k < teeth; k++)
    for (const [f, r] of profile) {
      const a = rot + ((k + f) / teeth) * Math.PI * 2;
      out.push([cx + r * Math.cos(a), cy + r * Math.sin(a)]);
    }
  return out;
}

// Point-up hexagons of circumradius r, in rings around the centre cell.
export function hexGrid(cx, cy, r, rings) {
  const cells = [];
  for (let q = -rings; q <= rings; q++)
    for (let s = -rings; s <= rings; s++) {
      const ring = Math.max(Math.abs(q), Math.abs(s), Math.abs(q + s));
      if (ring > rings) continue;
      cells.push({ x: cx + Math.sqrt(3) * r * (q + s / 2), y: cy + 1.5 * r * s, ring });
    }
  return cells.sort((a, b) => a.ring - b.ring);
}

export const translate = (pts, dx, dy) => pts.map(p => [p[0] + dx, p[1] + dy]);
export const rotate = (pts, cx, cy, a) => {
  const c = Math.cos(a), s = Math.sin(a);
  return pts.map(([x, y]) => [cx + (x - cx) * c - (y - cy) * s, cy + (x - cx) * s + (y - cy) * c]);

export const scale = (pts, cx, cy, sx, sy = sx) => pts.map(([x, y]) => [cx + (x - cx) * sx, cy + (y - cy) * sy]);

export const rotX = ([x, y, z], a) => [x, y * Math.cos(a) - z * Math.sin(a), y * Math.sin(a) + z * Math.cos(a)];
export const rotY = ([x, y, z], a) => [x * Math.cos(a) + z * Math.sin(a), y, -x * Math.sin(a) + z * Math.cos(a)];
export const rotZ = ([x, y, z], a) => [x * Math.cos(a) - y * Math.sin(a), x * Math.sin(a) + y * Math.cos(a), z];

// Camera sits at z = -f looking along +z; f = Infinity is orthographic.
export function project([x, y, z], { cx = 960, cy = 540, f = Infinity } = {}) {
  const s = Number.isFinite(f) ? f / (f + z) : 1;
  return [cx + x * s, cy + y * s];
}

export function cube(edge) {
  const h = edge / 2;
  const verts = [[-h, -h, -h], [h, -h, -h], [h, h, -h], [-h, h, -h], [-h, -h, h], [h, -h, h], [h, h, h], [-h, h, h]];
  const faces = [[0, 1, 2, 3], [5, 4, 7, 6], [4, 0, 3, 7], [1, 5, 6, 2], [4, 5, 1, 0], [3, 2, 6, 7]];
  const edges = [];
  for (const f of faces)
    for (let i = 0; i < 4; i++) {
      const a = f[i], b = f[(i + 1) % 4];
      if (!edges.some(([p, q]) => (p === a && q === b) || (p === b && q === a))) edges.push([a, b]);
    }
  return { verts, edges, faces };
}

export function cubeLines(edge, rot = { x: 0, y: 0, z: 0 }, cam = {}) {
  const { verts, edges, faces } = cube(edge);
  const tv = verts.map(v => rotZ(rotX(rotY(v, rot.y), rot.x), rot.z));
  const facing = faces.map(([a, b, c]) => {
    const u = tv[b].map((v, i) => v - tv[a][i]), w = tv[c].map((v, i) => v - tv[a][i]);
    return u[0] * w[1] - u[1] * w[0] < -1e-6; // normal z toward the camera
  });
  const out = { visible: [], hidden: [] };
  for (const [a, b] of edges) {
    const seen = faces.some((f, i) => facing[i] && f.includes(a) && f.includes(b));
    (seen ? out.visible : out.hidden).push([project(tv[a], cam), project(tv[b], cam)]);
  }
  return out;
}
```

```js
export function flatten(commands, steps = 8) {
  const contours = [];
  let cur = null, x = 0, y = 0;
  for (const c of commands) {
    if (c.type === 'M') { cur = [[c.x, c.y]]; contours.push(cur); }
    else if (c.type === 'L') cur.push([c.x, c.y]);
    else if (c.type === 'Q')
      for (let i = 1; i <= steps; i++) {
        const t = i / steps, m = 1 - t;
        cur.push([m * m * x + 2 * m * t * c.x1 + t * t * c.x, m * m * y + 2 * m * t * c.y1 + t * t * c.y]);
      }
    else if (c.type === 'C')
      for (let i = 1; i <= steps; i++) {
        const t = i / steps, m = 1 - t;
        cur.push([
          m * m * m * x + 3 * m * m * t * c.x1 + 3 * m * t * t * c.x2 + t * t * t * c.x,
          m * m * m * y + 3 * m * m * t * c.y1 + 3 * m * t * t * c.y2 + t * t * t * c.y,
        ]);
      }
    if (c.type !== 'Z') { x = c.x; y = c.y; }
  }
  return contours.filter(c => c.length > 2);
}

// Glyphs are looked up per character, not through stringToGlyphs, so each
// glyph stays paired with its character for per-letter animation.
export function layout(font, text, { size, x = 0, y = 0, tracking = 0, align = 'left' } = {}) {
  const k = size / font.unitsPerEm;
  const chars = [...text];
  const gl = chars.map(ch => font.charToGlyph(ch));
  const offsets = [];
  let pen = 0;
  gl.forEach((g, i) => {
    offsets.push(pen);
    pen += g.advanceWidth * k;
    if (i < gl.length - 1) pen += tracking * size + font.getKerningValue(g, gl[i + 1]) * k;
  });
  const x0 = align === 'center' ? x - pen / 2 : align === 'right' ? x - pen : x;
  return {
    width: pen,
    size,
    glyphs: gl.map((g, i) => ({
      char: chars[i],
      x: x0 + offsets[i],
      y,
      advance: g.advanceWidth * k,
      contours: flatten(g.getPath(x0 + offsets[i], y, size).commands),
    })),
  };
}

export function bounds(glyphs) {
  const b = { x0: Infinity, y0: Infinity, x1: -Infinity, y1: -Infinity };
  for (const g of glyphs) for (const c of g.contours) for (const [x, y] of c) {
    if (x < b.x0) b.x0 = x; if (x > b.x1) b.x1 = x;
    if (y < b.y0) b.y0 = y; if (y > b.y1) b.y1 = y;
  }
  return b;
}

export function fit(font, text, width, opts = {}) {
  const b = bounds(layout(font, text, { ...opts, size: 100 }).glyphs);
  return (100 * width) / (b.x1 - b.x0);
}
```

```js
export function hatchLines(contours, angle, spacing) {
  const b = bbox(contours);
  const cx = (b.x0 + b.x1) / 2, cy = (b.y0 + b.y1) / 2;
  const R = Math.hypot(b.x1 - b.x0, b.y1 - b.y0) / 2 + spacing;
  const dx = Math.cos(angle), dy = Math.sin(angle), nx = -dy, ny = dx;
  const lines = [];
  for (let d = -R; d <= R; d += spacing)
    lines.push([[cx + nx * d - dx * R, cy + ny * d - dy * R], [cx + nx * d + dx * R, cy + ny * d + dy * R]]);
  return lines;
}
```

```js
import { drawGrid, tracePath, toPath, hatchLines } from './common.js';

export const colors = { bg: '#EDE6D5', grid: '27,62,210', line: '#16161A', accent: '#1B3ED2', solid: '#16161A' };

function specks(seed, count, alphaMax, size) {
  const c = new OffscreenCanvas(W, H);
  const g = c.getContext('2d');
  const r = rand('specks', seed);
  g.fillStyle = '#000';
  for (let i = 0; i < count; i++) {
    g.globalAlpha = alphaMax * r();
    g.fillRect(r() * W, r() * H, size * (0.4 + r()), size * (0.4 + r()));
  }
  return c;
}

function wobble(pts, amp, seed) {
  const r = rand(seed);
  const k1 = 0.004 + 0.004 * r(), k2 = 0.02 + 0.015 * r();
  const p1 = Math.PI * 2 * r(), p2 = Math.PI * 2 * r();
  const out = new Array(pts.length);
  let s = 0;
  for (let i = 0; i < pts.length; i++) {
    if (i > 0) s += Math.hypot(pts[i][0] - pts[i - 1][0], pts[i][1] - pts[i - 1][1]);
    const a = pts[Math.max(0, i - 1)], b = pts[Math.min(pts.length - 1, i + 1)];
    let nx = a[1] - b[1], ny = b[0] - a[0];
    const l = Math.hypot(nx, ny) || 1;
    nx /= l; ny /= l;
    const d = amp * (0.6 * Math.sin(k1 * s + p1) + 1.4 * Math.sin(k2 * s + p2));
    out[i] = [pts[i][0] + nx * d, pts[i][1] + ny * d];
  }
  return out;
}

export function begin(ctx, { t, frozen }) {
  tooth ??= specks(1, 260000, 0.55, 1.6);
  grain ??= specks(2, 90000, 0.07, 1.2);
  const { width, height } = ctx.canvas;
  if (!layer || layer.width !== width || layer.height !== height) layer = new OffscreenCanvas(width, height);
  const L = layer.getContext('2d');
  L.setTransform(1, 0, 0, 1, 0, 0);
  L.clearRect(0, 0, width, height);
  L.setTransform(ctx.getTransform());
  // The wobble phase steps 8 times a second, not every frame.
  const tick = frozen ? 0 : Math.floor(t * 8);

  function pencil(pts, { closed = false, color = 'line', width: w = 3, dashed = false, id }) {
    if (pts.length < 2) return;
    const base = resample(pts, Math.max(2, Math.ceil(length(pts, closed) / 3)), closed);
    const seed = hash(id, tick);
    L.strokeStyle = colors[color];
    L.lineCap = 'round';
    L.lineJoin = 'round';
    L.setLineDash(dashed ? [10, 9] : []);
    L.globalAlpha = 0.9; L.lineWidth = w;
    tracePath(L, wobble(base, 1, seed), closed); L.stroke();
    L.globalAlpha = 0.4; L.lineWidth = w / 2;
    tracePath(L, wobble(base, 2, seed + 1), closed); L.stroke();
    L.globalAlpha = 1;
    L.setLineDash([]);
  }

  return {
    typeSpacing: 7, typeOutline: 2.2, doubleOutline: true,
    bg() {
      ctx.fillStyle = colors.bg;
      ctx.fillRect(0, 0, W, H);
      ctx.save();
      ctx.globalCompositeOperation = 'multiply';
      ctx.drawImage(grain, 0, 0, W, H);
      ctx.restore();
      drawGrid(ctx, colors.grid);
    },
    stroke: pencil,
    fill(contours, { color = 'accent', mode = 'hatch', progress = 1, spacing = 9, angle = Math.PI / 4, width: w = 1.6, id }) {
      const path = toPath(contours);
      if (mode === 'solid') {
        L.fillStyle = colors[color]; L.globalAlpha = 0.9; L.fill(path, 'evenodd'); L.globalAlpha = 1;
        return;
      }
      L.save();
      L.clip(path, 'evenodd');
      const passes = mode === 'cross' ? [angle, -angle] : [angle];
      passes.forEach((a, k) => {
        const lines = hatchLines(contours, a, spacing);
        const n = Math.ceil(lines.length * progress);
        for (let i = 0; i < n; i++) pencil(lines[i], { color, width: w, id: `${id}:${k}:${i}` });
      });
      L.restore();
    },
    flush() {
      L.save();
      L.setTransform(1, 0, 0, 1, 0, 0);
      L.globalCompositeOperation = 'destination-out';
      L.drawImage(tooth, 0, 0, layer.width, layer.height);
      L.restore();
      ctx.save();
      ctx.setTransform(1, 0, 0, 1, 0, 0);
      ctx.globalCompositeOperation = 'multiply';
      ctx.drawImage(layer, 0, 0);
      ctx.restore();
    },
  };
}
```

```js
import * as paper from './paper.js';
import * as blueprint from './blueprint.js';
import * as hologram from './hologram.js';
import { toContours } from './common.js';
import { layout } from '../type.js';

export const inks = { paper, blueprint, hologram };

export function makePen(name, ctx, env) {
  const ink = inks[name];
  if (!ink) throw new Error(`unknown ink "${name}"; expected one of ${Object.keys(inks).join(', ')}`);
  const impl = ink.begin(ctx, env);
  let n = 0;
  return {
    name,
    colors: ink.colors,
    bg: () => impl.bg(),
    stroke: (pts, o = {}) => impl.stroke(pts, { id: `s${n++}`, ...o }),
    fill: (shape, o = {}) => impl.fill(toContours(shape), { id: `f${n++}`, ...o }),
    type(glyphs, { color = 'line', progress = 1, id = `t${n++}` } = {}) {
      const contours = glyphs.flatMap(g => g.contours);
      if (!contours.length) return;
      impl.fill(contours, { color, spacing: impl.typeSpacing, progress, id });
      contours.forEach((c, i) => {
        impl.stroke(c, { closed: true, color, width: impl.typeOutline, id: `${id}a${i}` });
        if (impl.doubleOutline) impl.stroke(c, { closed: true, color, width: impl.typeOutline * 0.7, id: `${id}b${i}` });
      });
    },
    text(str, { x, y, size = 26, weight = 'xbold', tracking = 0.2, align = 'left', color = 'line' }) {
      const lay = layout(env.fonts[weight], str, { size, x, y, tracking, align });
      const contours = lay.glyphs.flatMap(g => g.contours);
      if (contours.length) impl.fill(contours, { mode: 'solid', color, id: `x${n++}` });
      return lay;
    },
    flush: () => impl.flush(),
  };
}
```

```js
import * as opentype from '/vendor/opentype/opentype.module.js';
import { makeClock } from './clock.js';
import * as ease from './ease.js';
import * as geom from './geom.js';
import * as type from './type.js';
import { makePen } from './ink/index.js';
import { drawLabels, LABEL_BOXES } from './labels.js';

const W = 1920, H = 1080;
const parse = opentype.parse ?? opentype.default.parse;

async function loadFont(url) {
  const res = await fetch(url);
  if (!res.ok) throw new Error(`font ${url}: HTTP ${res.status}`);
  return parse(await res.arrayBuffer());
}

const REQUIRED = ['slug', 'bpm', 'bars', 'barNames', 'cues', 'palette', 'draw'];

export async function boot(canvas, filmUrl) {
  const [mod, black, xbold, semi] = await Promise.all([
    import(filmUrl),
    loadFont('/fonts/Geist-Black.otf'),
    loadFont('/fonts/Geist-ExtraBold.otf'),
    loadFont('/fonts/Geist-SemiBold.otf'),
  ]);
  const film = mod.default;
  const missing = REQUIRED.filter(k => film?.[k] === undefined);
  if (missing.length) throw new Error(`${filmUrl} default export is missing: ${missing.join(', ')}`);
  if (film.barNames.length !== film.bars) throw new Error(`barNames has ${film.barNames.length} names for ${film.bars} bars`);
  const clock = makeClock({ bpm: film.bpm, bars: film.bars });
  const fonts = { black, xbold, semi };

  function renderAt(t, { frozen = false, scale = 1 } = {}) {
    const w = Math.round(W * scale), h = Math.round(H * scale);
    if (canvas.width !== w || canvas.height !== h) { canvas.width = w; canvas.height = h; }
    const ctx = canvas.getContext('2d');
    ctx.setTransform(1, 0, 0, 1, 0, 0);
    ctx.clearRect(0, 0, w, h);
    ctx.setTransform(scale, 0, 0, scale, 0, 0);
    const rest = [];
    const env = { t, frozen, fonts };
    const pen = name => makePen(name, ctx, env);
    // Draws the same geometry twice: in `outside` ink beyond the clip, in `inside` ink within it.
    const split = (clip, outside, inside, fn) => {
      const inner = new Path2D();
      inner.moveTo(...clip[0]);
      for (let i = 1; i < clip.length; i++) inner.lineTo(...clip[i]);
      inner.closePath();
      const outer = new Path2D();
      outer.rect(0, 0, W, H);
      outer.addPath(inner);
      for (const [path, rule, name] of [[outer, 'evenodd', outside], [inner, 'nonzero', inside]]) {
        ctx.save();
        ctx.clip(path, rule);
        const p = pen(name);
        p.bg();
        fn(p);
        p.flush();
        ctx.restore();
      }
    };
    const api = {
      t, W, H, ctx, clock, ease, geom, type, fonts, frozen, pen, split,
      labels: p => drawLabels(p, { clock, t, barNames: film.barNames }),
      rest: box => rest.push(box),
    };
    film.draw(ctx, t, api);
    return { rest, labels: LABEL_BOXES };
  }

  return { film, clock, renderAt };
}
```

```js
import http from 'node:http';
import fs from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import { createRequire } from 'node:module';
import { chromium } from 'playwright';

export const ENGINE = path.dirname(fileURLToPath(import.meta.url));
const SKILL = path.dirname(ENGINE);
const require = createRequire(import.meta.url);
const OPENTYPE = path.join(path.dirname(require.resolve('opentype.js/package.json')), 'dist');
const TYPES = { '.js': 'text/javascript', '.mjs': 'text/javascript', '.html': 'text/html', '.otf': 'font/otf', '.ttf': 'font/ttf', '.png': 'image/png', '.json': 'application/json' };

function serve(mounts) {
  const server = http.createServer((req, res) => {
    const { pathname } = new URL(req.url, 'http://x');
    for (const [prefix, dir] of mounts) {
      if (!pathname.startsWith(prefix + '/')) continue;
      const file = path.resolve(dir, decodeURIComponent(pathname.slice(prefix.length + 1)));
      if (!file.startsWith(dir + path.sep)) { res.writeHead(403).end(); return; }
      fs.readFile(file, (err, body) => {
        if (err) { res.writeHead(404).end(`${pathname} not found`); return; }
        res.writeHead(200, { 'content-type': TYPES[path.extname(file)] ?? 'application/octet-stream', 'cache-control': 'no-store' }).end(body);
      });
      return;
    }
    res.writeHead(404).end();
  });
  return new Promise(resolve => server.listen(0, '127.0.0.1', () => resolve(server)));
}

export async function serveFilm(filmDir) {
  const film = path.resolve(filmDir);
  if (!fs.existsSync(path.join(film, 'scenes.js'))) throw new Error(`${path.join(film, 'scenes.js')}: scenes.js not found`);
  const server = await serve([['/engine', ENGINE], ['/fonts', path.join(SKILL, 'fonts')], ['/vendor/opentype', OPENTYPE], ['/film', film]]);
  const url = `http://127.0.0.1:${server.address().port}/engine/render.html?film=/film/scenes.js`;
  return { url, close: () => new Promise(r => server.close(r)) };
}

export async function openRenderer(filmDir, { pages = 1 } = {}) {
  const site = await serveFilm(filmDir);
  let browser;
  try {
    browser = await chromium.launch();
  } catch (e) {
    await site.close();
    throw new Error(`Chromium failed to launch. Run: npx --prefix ${ENGINE} playwright install chromium\n${e.message}`);
  }
  const open = async () => {
    const page = await browser.newPage({ viewport: { width: 1920, height: 1080 } });
    await page.goto(site.url + '&headless=1');
    await page.waitForFunction(() => window.__ready || window.__error, null, { timeout: 60000 });
    const err = await page.evaluate(() => window.__error);
    if (err) throw new Error(err);
    return page;
  };
  const list = [];
  try {
    for (let i = 0; i < pages; i++) list.push(await open());
  } catch (e) {
    await browser.close();
    await site.close();
    throw e;
  }

  const meta = await list[0].evaluate(() => {
    const { film, clock } = window.__stage;
    return {
      slug: film.slug, bpm: film.bpm, bars: film.bars, barNames: film.barNames, cues: film.cues, palette: film.palette,
      duration: clock.duration, frames: clock.frames, fps: clock.fps, spb: clock.spb, totalBeats: clock.totalBeats,
    };
  });

  async function frame(t, opts = {}, page = list[0]) {
    const r = await page.evaluate(([t, opts]) => {
      const res = window.__stage.renderAt(t, opts);
      return { png: document.getElementById('c').toDataURL('image/png'), rest: res.rest, labels: res.labels };
    }, [t, opts]);
    return { png: Buffer.from(r.png.split(',')[1], 'base64'), rest: r.rest, labels: r.labels };
  }

  async function pixels(t, opts = {}, page = list[0]) {
    const r = await page.evaluate(([t, opts]) => {
      const res = window.__stage.renderAt(t, opts);
      const c = document.getElementById('c');
      const data = c.getContext('2d').getImageData(0, 0, c.width, c.height).data;
      let bin = '';
      for (let i = 0; i < data.length; i += 0x8000) bin += String.fromCharCode.apply(null, data.subarray(i, i + 0x8000));
      return { b64: btoa(bin), width: c.width, height: c.height, rest: res.rest, labels: res.labels };
    }, [t, opts]);
    return { data: new Uint8Array(Buffer.from(r.b64, 'base64')), width: r.width, height: r.height, rest: r.rest, labels: r.labels };
  }

  return {
    meta, pages: list, frame, pixels,
    close: async () => { await browser.close(); await site.close(); },
  };
}
```

```js
// Units from the character sheet: body 76 x 54, arms 24 x 16, legs 11 x 33,
// eyes 8 x 14. 124 units = body plus both arm stubs; origin between the feet.
const UNITS_WIDE = 124;
const LEGS = [-27, -9, 9, 27];
const ARM_UP = (-58 * Math.PI) / 180;

export function mascot(pen, { x, y, width = 250, pose = 'stand', t = 0, facing = 1 } = {}) {
  const s = width / UNITS_WIDE;
  const run = pose === 'run';
  const phase = Math.sin(2 * Math.PI * 3 * t); // 6 steps a second, alternating pairs
  const lift = i => (run ? Math.max(0, i % 2 === 0 ? phase : -phase) * 9 : 0);
  const tilt = run ? ((7 * Math.PI) / 180) * facing : 0;
  const c = Math.cos(tilt), sn = Math.sin(tilt);
  const T = pts => pts.map(([u, v]) => {
    const xu = u * facing;
    return [x + s * (xu * c - v * sn), y + s * (xu * sn + v * c)];
  });

  const parts = [];
  LEGS.forEach((lx, i) => parts.push({ pts: T(roundRect(lx - 5.5, -33 - lift(i), 11, 33, 3, 2)) }));
  const body = T(roundRect(-38, -87, 76, 54, 9));
```

```js
#!/usr/bin/env node
import os from 'node:os';
import { fileURLToPath } from 'node:url';
import { openRenderer } from './frames.mjs';

const MARGIN = { x: 150, y: 90 };
const SWEEP_SCALE = 0.25;
const HOLD_LIMIT = 30; // frames at 60 fps = 0.5 s
const PALETTE_TOL = 48;
const PALETTE_MAX_OUT = 0.005;

const hex = h => [1, 3, 5].map(i => parseInt(h.slice(i, i + 2), 16));

export function checkBeats(m) {
  const stray = m.cues.filter(c => c < -0.05 - 1e-6 || c >= m.duration);
  const missing = [];
  for (let k = 0; k < m.totalBeats; k++) {
    const beat = k * m.spb;
    if (!m.cues.some(c => c >= beat - 0.05 - 1e-6 && c <= beat + 1e-6)) missing.push(k + 1);
  }
  const ok = !missing.length && !stray.length;
  const detail = ok ? `${m.totalBeats} beats cued`
    : [missing.length && `beats without a cue: ${missing.join(', ')}`, stray.length && `cues outside the film: ${stray.join(', ')}`].filter(Boolean).join('; ');
  return { name: 'beats', ok, detail };
}

function meanDiff(a, b) {
  let d = 0, n = 0;
  for (let i = 0; i < a.data.length; i += 4) { d += Math.abs(a.data[i] - b.data[i]) + Math.abs(a.data[i + 1] - b.data[i + 1]) + Math.abs(a.data[i + 2] - b.data[i + 2]); n += 3; }
  return d / n;
}

function identical(a, b, masks) {
  const s = SWEEP_SCALE;
  for (let y = 0; y < a.height; y++)
    for (let x = 0; x < a.width; x++) {
      if (masks.some(m => x >= m.x * s && x < (m.x + m.w) * s && y >= m.y * s && y < (m.y + m.h) * s)) continue;
      const i = (y * a.width + x) * 4;
      if (Math.abs(a.data[i] - b.data[i]) > 2 || Math.abs(a.data[i + 1] - b.data[i + 1]) > 2 || Math.abs(a.data[i + 2] - b.data[i + 2]) > 2) return false;
    }
  return true;
}

function segDist(p, a, b) {
  const ab = [b[0] - a[0], b[1] - a[1], b[2] - a[2]];
  const ap = [p[0] - a[0], p[1] - a[1], p[2] - a[2]];
  const L = ab[0] ** 2 + ab[1] ** 2 + ab[2] ** 2;
  const u = L ? Math.max(0, Math.min(1, (ap[0] * ab[0] + ap[1] * ab[1] + ap[2] * ab[2]) / L)) : 0;
  return Math.hypot(ap[0] - ab[0] * u, ap[1] - ab[1] * u, ap[2] - ab[2] * u);
}

// A pixel is in palette if it lies near the blend line between any two
// palette colours; anti-aliasing and alpha only ever produce such blends.
function outsidePalette(px, palette) {
  const cols = palette.map(hex);
  const pairs = [];
  for (let i = 0; i < cols.length; i++) for (let j = i; j < cols.length; j++) pairs.push([cols[i], cols[j]]);
  const cache = new Map();
  let out = 0;
  for (let i = 0; i < px.data.length; i += 4) {
    const key = (px.data[i] << 16) | (px.data[i + 1] << 8) | px.data[i + 2];
    let bad = cache.get(key);
    if (bad === undefined) {
      const p = [px.data[i], px.data[i + 1], px.data[i + 2]];
      bad = !pairs.some(([a, b]) => segDist(p, a, b) <= PALETTE_TOL);
      cache.set(key, bad);
    }
    if (bad) out++;
  }
  return out / (px.data.length / 4);
}

export async function runChecks(filmDir, { only, range, workers = Math.max(1, Math.min(4, os.cpus().length - 1)) } = {}) {
  const want = name => !only || only.includes(name);
  const r = await openRenderer(filmDir, { pages: workers });
  const results = [];
  try {
    const m = r.meta;
    if (want('beats')) results.push(checkBeats(m));
    if (want('loop')) {
      const a = await r.pixels(0, { frozen: true, scale: 0.5 });
      const b = await r.pixels(m.duration, { frozen: true, scale: 0.5 });
      const d = meanDiff(a, b);
      results.push({ name: 'loop', ok: d < 1, detail: d < 1 ? 'last frame equals the first' : `last frame differs from the first (mean diff ${d.toFixed(2)}/255)` });
    }
    if (want('border') || want('holds') || want('palette')) {
      const f0 = range ? Math.round(range[0] * m.fps) : 0;
      const f1 = range ? Math.round(range[1] * m.fps) : m.frames;
      const same = new Array(f1).fill(false);
      const borderHits = [], paletteHits = [];
      const chunk = Math.ceil((f1 - f0) / r.pages.length);
      await Promise.all(r.pages.map(async (page, w) => {
        const a = f0 + w * chunk, b = Math.min(f1, a + chunk);
        let prev = a > 0 ? await r.pixels((a - 1) / m.fps, { frozen: true, scale: SWEEP_SCALE }, page) : null;
        for (let i = a; i < b; i++) {
          const t = i / m.fps;
          const px = await r.pixels(t, { frozen: true, scale: SWEEP_SCALE }, page);
          for (const box of px.rest)
            if (box.x < MARGIN.x - 0.5 || box.y < MARGIN.y - 0.5 || box.x + box.w > 1920 - MARGIN.x + 0.5 || box.y + box.h > 1080 - MARGIN.y + 0.5)
              borderHits.push(`t=${t.toFixed(3)} rest box ${JSON.stringify(box)}`);
          if (prev) same[i] = identical(prev, px, px.labels);
          if (want('palette') && i % Math.round(m.spb * m.fps) === 0) {
            const frac = outsidePalette(px, m.palette);
            if (frac > PALETTE_MAX_OUT) paletteHits.push(`t=${t.toFixed(2)} ${(frac * 100).toFixed(1)}%`);
          }
          prev = px;
        }
      }));
      if (want('border')) results.push({ name: 'border', ok: !borderHits.length, detail: borderHits.length ? `${borderHits.length} frames: ${borderHits.slice(0, 5).join('; ')}` : 'border clear' });
      if (want('holds')) {
        const holds = [];
        let run = 1;
        for (let i = f0 + 1; i <= f1; i++) {
          if (i < f1 && same[i]) { run++; continue; }
          if (run > HOLD_LIMIT) holds.push(`hold of ${run} frames ending t=${((i - 1) / m.fps).toFixed(2)}`);
          run = 1;
        }
        results.push({ name: 'holds', ok: !holds.length, detail: holds.length ? holds.join('; ') : 'no hold over 0.5 s' });
      }
      if (want('palette')) results.push({ name: 'palette', ok: !paletteHits.length, detail: paletteHits.length ? `pixels outside the palette at ${paletteHits.join(', ')}` : 'palette clean' });
    }
  } finally {
    await r.close();
  }
  return results;
}

if (process.argv[1] === fileURLToPath(import.meta.url)) {
  const args = process.argv.slice(2);
  const dir = args.find(a => !a.startsWith('--'));
  const opt = k => { const i = args.indexOf(`--${k}`); return i >= 0 ? args[i + 1] : undefined; };
  if (!dir) { console.error('usage: check.mjs <filmDir> [--only beats,loop,border,holds,palette] [--range t0,t1]'); process.exit(2); }
  const results = await runChecks(dir, { only: opt('only')?.split(','), range: opt('range')?.split(',').map(Number) });
  for (const r of results) console.log(`${r.ok ? 'pass' : 'FAIL'}  ${r.name.padEnd(8)} ${r.detail}`);
  process.exit(results.every(r => r.ok) ? 0 : 1);
}
```

```js
#!/usr/bin/env node
import fs from 'node:fs';
import os from 'node:os';
import path from 'node:path';
import { spawn } from 'node:child_process';
import { fileURLToPath } from 'node:url';
import ffmpeg from 'ffmpeg-static';
import { openRenderer } from './frames.mjs';

function run(cmd, args) {
  return new Promise((resolve, reject) => {
    const p = spawn(cmd, args, { stdio: ['ignore', 'ignore', 'pipe'] });
    let err = '';
    p.stderr.on('data', d => { err += d; });
    p.on('close', code => (code === 0 ? resolve() : reject(new Error(`ffmpeg exited ${code}\n${err.slice(-2000)}`))));
  });
}

export async function exportFilm(filmDir, { out, workers = Math.max(1, Math.min(6, os.cpus().length - 1)), frames } = {}) {
  const r = await openRenderer(filmDir, { pages: workers });
  try {
    const { fps, slug } = r.meta;
    const [from, to] = frames ?? [0, r.meta.frames];
    const dir = path.join(filmDir, 'out', 'frames');
    fs.rmSync(dir, { recursive: true, force: true });
    fs.mkdirSync(dir, { recursive: true });
    let next = from, done = 0;
    await Promise.all(r.pages.map(async page => {
      while (next < to) {
        const i = next++;
        const { png } = await r.frame(i / fps, {}, page);
        fs.writeFileSync(path.join(dir, `${String(i - from).padStart(5, '0')}.png`), png);
        if (++done % 60 === 0) process.stderr.write(`\r${done}/${to - from} frames`);
      }
    }));
    process.stderr.write('\n');
    const mp4 = out ?? path.join(filmDir, 'out', `${slug}.mp4`);
    await run(ffmpeg, ['-y', '-framerate', String(fps), '-i', path.join(dir, '%05d.png'), '-c:v', 'libx264', '-pix_fmt', 'yuv420p', '-crf', '16', '-movflags', '+faststart', mp4]);
    return mp4;
  } finally {
    await r.close();
  }
}
```

```js
const barModule = n => `// Bar ${n}. Owns film time [${(n - 1) * 2 - 0.05}, ${n * 2 - 0.05}).
export const cues = [${[0, 1, 2, 3].map(k => ((n - 1) * 4 + k) * 0.5 - 0.05).join(', ')}];

export function draw(t, api) {
  const p = api.pen('paper');
  p.bg();
  p.stroke(api.geom.line(330, 540, 1590, 540));
  api.labels(p);
  p.flush();
}
`;

export function newFilm(root, slug, { bpm = 120, bars = 15 } = {}) {
  if (!/^[a-z0-9-]+$/.test(slug)) throw new Error(`slug "${slug}" must be lowercase letters, digits and dashes`);
  const dir = path.join(root, 'films', slug);
  if (fs.existsSync(dir)) throw new Error(`${dir} already exists`);
  fs.mkdirSync(path.join(dir, 'bars'), { recursive: true });
  const nums = Array.from({ length: bars }, (_, i) => i + 1);
  for (const n of nums) fs.writeFileSync(path.join(dir, 'bars', `${pad(n)}.js`), barModule(n));
  fs.writeFileSync(path.join(dir, 'shared.js'), '// Geometry handed from one bar to the next. Each bar starts from the state the previous one ends in.\n');
  fs.writeFileSync(path.join(dir, 'brief.md'), `# ${slug}\n`);
  fs.writeFileSync(path.join(dir, 'scenes.js'), `${nums.map(n => `import * as b${pad(n)} from './bars/${pad(n)}.js';`).join('\n')}

const BARS = [${nums.map(n => `b${pad(n)}`).join(', ')}];
const BAR = ${(60 / bpm) * 4};

  bpm: ${bpm},
  bars: ${bars},
  barNames: [${nums.map(n => `'BAR ${n}'`).join(', ')}],
  palette: ['#EDE6D5', '#1B3ED2', '#45F0DD', '#07080A', '#16161A', '#FFFFFF'],
  cues: BARS.flatMap(b => b.cues),
  // A bar owns the 0.05 s lead-in before its first beat, so moves that land
  // on a downbeat start inside the bar that animates them.
  draw(ctx, t, api) {
    BARS[Math.min(BARS.length - 1, Math.floor((t + 0.05) / BAR))].draw(t, api);
  },
```

````markdown
# Scene handoffs

There are no opacity transitions. The new ink arrives as geometry.

## Flood shape

A shape from the current scene grows past the frame with a hard edge. Inside it, the next ink; outside it, the current one. Both sides draw the same geometry.

```js
const r = 96 + (2400 - 96) * api.ease.expoIn(api.clock.local(t, 9.55, 0.45));
api.split(api.geom.polygon(960, 540, r, 6), 'paper', 'blueprint', p => {
  drawHoneycomb(p);
  api.labels(p);
});
```

## Scan line

One horizontal line sweeps the frame. Above it, one ink; below it, the other. Draw the line itself in the incoming ink's `line` colour, full width, 3 px.

```js
const y = 1080 * api.ease.expoInOut(api.clock.local(t, 17.95, 0.5));
api.split([[0, y], [1920, y], [1920, 1080], [0, 1080]], 'hologram', 'blueprint', p => {
  drawRing(p);
  api.labels(p);
});
```

The ink names fix which side is which: the first ink is outside the clip, the second inside. For a downward sweep that reveals hologram, the area above `y` (outside the clip) is hologram.

## Rules

- Call `api.labels(p)` inside the split callback so the labels change ink with everything else.
- Geometry functions take the pen as an argument and never reach for a specific ink.
- A sweep lasts 0.4 to 0.5 s and starts 0.05 s before its beat.
````

```js
import test from 'node:test';
import assert from 'node:assert/strict';
import fs from 'node:fs';
import { openRenderer } from '../plugins/showreel/skills/showreel/engine/frames.mjs';

const FILM = new URL('../examples/claude-motion-designer', import.meta.url).pathname;
const TIMES = [1.0, 9.75, 18.25, 27.25];

// Goldens are rendered with the wobble frozen at scale 0.5 and stored as raw RGBA,
// so the comparison is pixel-level and independent of PNG encoders.
test('reference film matches its golden frames', async () => {
  const r = await openRenderer(FILM);
  try {
    for (const t of TIMES) {
      const file = `${FILM}/golden/t-${t.toFixed(3).padStart(6, '0')}.rgba`;
      const px = await r.pixels(t, { frozen: true, scale: 0.5 });
      if (process.env.UPDATE_GOLDEN) { fs.mkdirSync(`${FILM}/golden`, { recursive: true }); fs.writeFileSync(file, px.data); continue; }
      const want = fs.readFileSync(file);
      let d = 0;
      for (let i = 0; i < want.length; i++) d += Math.abs(want[i] - px.data[i]);
      assert.ok(d / want.length < 2, `t=${t}: mean diff ${(d / want.length).toFixed(2)} exceeds 2/255`);
    }
  } finally { await r.close(); }
});
```
